# ScribeOS 🖋️

A zero-dependency, ultra-minimalist creative writing and story studio designed for distraction-free prose. ScribeOS runs entirely client-side, featuring a pitch-black OLED aesthetic and persistent local storage to ensure you never lose a keystroke. 

Crafted with focus in mind by BocchiTheTrader.

## ✨ Features

* **Multi-Project Architecture:** Manage multiple manuscripts, books, or story universes simultaneously.
* **Chapter Tree Navigation:** Instantly switch between scenes and chapters with drag-and-drop reordering.
* **Floating Scratchpad:** Spawn color-coded, draggable sticky notes for worldbuilding, character flaws, and plot holes.
* **Narrative Frameworks:** 1-click insertion of classic story templates (The Hero's Journey, Save the Cat!, Three-Act Structure, etc.).
* **Pro Writer HUD:** Real-time telemetry for word counts, reading time, and daily writing goals.
* **Zen & Typewriter Modes:** Hide all UI elements and keep your active sentence perfectly centered on the screen.
* **Export Matrix:** Download your work as pristine Markdown, render it directly to PDF, or export/restore full JSON backups.
* **Client-Side Persistence:** Aggressive `localStorage` auto-saving. No servers, no accounts, no database required.

1- Open the folder.
2- Double-click index.html to open it in your preferred web browser.
3- Start writing. Good luck.
